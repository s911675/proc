사용자 / 권한

  • dept 부서 (자기참조 계층)
  • users 사용자
  • role 역할 = 권한 묶음, 계층형(parent_role_id) — 상위 역할은 하위 역할 권한 상속 (예: ADMIN > MANAGER > USER)
  • user_role 한 사용자가 여러 역할 보유 (N:M) — 기본 역할 + 작은 추가 역할
  • permission 가장 작은 권한 단위 (Spring Security authority로 사용)
  • role_permission 역할에 권한 부여 (N:M)

상태 흐름 정의

  • work_type 업무 유형
  • work_status 유형별 상태 목록 (시작/종료 표시)
  • work_transition 허용된 상태 이동 + 필요 권한 1개

실행

  • work_item 실제 업무 건, 현재 상태 보유
  • work_status_history 상태 변경 이력 (INSERT 전용)

권한 체크: 사용자의 역할에서 시작해 하위 역할(parent_role_id로 자기를 가리키는 역할)을 모두 모으고, 그 역할들의 권한 중에 전이의 필요 권한이 있으면 전이 가능 (MySQL 8 WITH RECURSIVE). 로그인 시 같은 방식으로 사용자 권한 목록을 만들어 Spring Security authority로 사용.

WITH RECURSIVE eff_role AS (
    SELECT ur.role_id FROM user_role ur WHERE ur.user_id = #{userId}
    UNION
    SELECT c.role_id FROM role c JOIN eff_role e ON c.parent_role_id = e.role_id
)
SELECT EXISTS (
    SELECT 1 FROM eff_role e
      JOIN role_permission rp ON rp.role_id = e.role_id
      JOIN work_transition t  ON t.permission_id = rp.permission_id
     WHERE t.transition_id = #{transitionId}
);

주요 인덱스: work_transition UK(type_code, from_status, to_status) · work_item(type_code, current_status) · work_item(owner_id) · work_status_history(item_id, created_at)
